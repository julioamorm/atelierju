# Doces da Ju - Landing Page

Landing page profissional e responsiva para o ateliê de doces artesanais **Doces da Ju** (Juliana), especializada em bolos e doces personalizados com entrega em Belo Horizonte e Betim.

## ✨ O que tem na página

- Design elegante com identidade visual em tons de creme, blush e marrom quente
- Hero com foto principal do bolo
- Seção de Cardápio (Doces e Bolos) com visualização em lightbox
- Seção de Conexão Emocional
- 3 Cards de Benefícios
- Como Funciona em 3 passos
- Depoimentos de clientes
- CTA final forte com WhatsApp
- Totalmente responsiva (mobile, tablet e desktop)
- Integração direta com WhatsApp (número real configurado)

## 🚀 Como usar

1. Faça o download/clone deste repositório
2. Abra o arquivo `index.html` diretamente no navegador (ou sirva com qualquer servidor estático)
3. Personalize o número de WhatsApp e links de Instagram conforme necessário (procure por `553184956819` e `julianaamormino`)

## 🛠️ Tecnologias

- HTML5 + Tailwind CSS (via CDN)
- Vanilla JavaScript (lightbox, smooth scroll, menu mobile)
- Google Fonts (Playfair Display + Inter)
